# 🦉 Athena – AI Investment Assistant (Frontend)

React Native mobile app for Athena, a personal BIST stock investment assistant.
Displays AI-powered buy/sell signals, tracks portfolio positions, and includes
a conversational interface powered by Groq (Llama 3.3 70B).

## ⚙️ Tech Stack
- React Native + Expo
- Django REST API (Athena-Backend)
- React Navigation

## 💡 Features
- Market dashboard: BIST100, USD/TRY, gold, crypto live data
- Budget planner: Athena scans 80 stocks and recommends positions
- Position tracker: real-time P&L with stop/target alerts
- Paper trading with backtesting
- Athena Chat: conversational AI with context memory
- Performance history: win rate, total P&L

## 🔗 Related
- Backend: [Athena Django API](https://github.com/Busrwa/Athena-Backend)

## 🚀 Getting Started
```bash
git clone https://github.com/Busrwa/Athena-Frontend.git
cd Athena-Frontend
npm install
npx expo start
```
